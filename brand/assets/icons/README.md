The Market's 19 line icons: 24px grid, 2px stroke, round caps and joins, drawn in `ink` (#1a2226) for light grounds. In the UI, render them with `Icon` so they take `currentColor` in both themes. Always pair an icon with a word. Meanings: calendar = date, clock = time, map-pin = place, card = payments / SNAP/EBT, basket = shopping, carrot and leaf = produce, sun and rain = weather, music = live music, tent = stalls, info / alert / check-circle / x-circle = notice tones, arrow-right = go, instagram / facebook / mail = contact.
